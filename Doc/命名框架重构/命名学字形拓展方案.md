# 命名学字形拓展方案

> 历史方案。新的设计见[原版词组与姓氏覆盖设计](原版词组与姓氏覆盖设计.md)。

2026-11-19 · 已接入。首批只做生物和城市。原版命名学只扩展字形和预览，下方沿用原版词组输入，不再另设编辑栏。

## 一条排列，一套操作

在文化档案的原版「命名学」里，保留分类、预览、排列条、字形盘、词组编辑区的位置。姓氏、名字、地名、地名后缀是按命名对象出现的字形，和原版字形共用同一个字形盘与排列条。移除「原版字形」折叠开关、单独的「＋后缀」按钮与独立的部件设置区。页面打开后直接能看到排列和可用字形，未选中字形时不占用设置空间。

```text
预览      中原话 ▾       澄江-府
分类      生物  家族  氏族  城市  国家
排列      [地名]  [连字符]  [后缀]
字形盘    … [地名] [空格] [后缀] [连字符] …
词组编辑  原版输入框 [府]
```

- 从字形盘添加字形，在原版排列条拖动换序，沿用原版移除操作。新增字形和原版符号可以直接相邻，例如 `[地名] [连字符] [后缀]`。生物字形不出现在城市分类，反之亦然。
- 点预览中的后缀或可定位的原版词组，打开原版词组输入框。原版规则可能把若干字形合成为一段文字，无法准确定位时整段只作预览。右键点击排列中的后缀也能打开原版词组输入框，即使这次预览没有抽到后缀。
- 后缀可通过原版词组输入改字。姓氏继承、名字词库和其他扩展规则直接读取文化、语言与命名包配置，命名学里不增加对应的下拉或设置栏。有效的排列编辑自动生效，无效排列留在预览中提示，保持上次有效规则。
- 预览沿用原来的区域，保留一行名字和一个语言下拉，切换语言只改变这次预览。窄窗按宽度自动换行，保留原版字形的点击尺寸；不为了塞进两行而缩小图标。

## 同一排列决定预览和取名

当前文化和命名包为生物、城市提供默认排列。玩家打开页面时直接看到解析出的有效排列。拖动、添加和删除均编辑这份排列，调整字形设置只改对应字段。预览与实际取名执行同一个排列和相同的字形语义；加进第一个原版符号时只发生一次插入，不改变其他字形的取词、继承、顺序和有效的分隔行为。有效排列可以由包规则与玩家覆盖解析得出，不需要把包复制进存档。

首批只转换已知、可无损表达的生物和城市规则。复杂规则不能逐字形准确展示时，不把猜出来的排列显示成真实规则；保持原有生成，等有对应字形语义再通过同一编辑器接入。继续使用原版排列与普通字形行为；扩展字形标明适用目标，并由现有命名服务解析词库或继承值。其他命名入口不需要切换到字形实现。

- 「欧阳青」显示为 `[姓氏] [名字]`，已有双字名规则可以显示原有的两个名字字形。没有可继承的姓时，按当前文化规则和语言从命名包指定的姓氏词库抽取，例如内置的「常见中文姓氏」里就有「欧阳」。抽到后保存为生物的姓氏。切换河谷话可以换成「欧阳岚」，继承来的复姓作为一个整体保留。
- 「澄江府」显示为 `[地名] [后缀]`。点「府」改成「州」，从同一盘添加原版连字符并拖到地名和后缀之间，即可得到「澄江-州」。没有后缀时，从字形盘添加「后缀」，不用另找入口。
- 「约翰·史密斯」按文化排列显示名字在前、姓在后。原有写法和分隔符要准确映射；如果间隔号没有可复用的原版字形，注册成同盘字形，并保留既有存档的实际写法。

## 兼容与实施边界

继续读取旧存档中的原版排列和本模组已保存的编辑，已有原版排列与已生效的中文设置按原来实际生效的规则还原。保留现有字形 ID 和剪贴板短码；导入旧原版序列仍用同一排列条。应用只影响今后的命名。没有改过的排列和字形设置随当前包更新；已改的顺序、固定文字与词库覆盖继续保留。临时卸包遇到无法解析的引用时保留编辑，生成使用可用的回退，装回后恢复。恢复默认以当前包的默认规则为准。

先用城市验证最小闭环，再接生物的姓氏继承与中西顺序。两块都通过后，删掉旧编辑器里的折叠状态和「第一次加原版字形就接管排列」的转换路径。暂不扩展其他类别，保留以后由其他模组声明自己的字形、目标和设置的接入点。

独立游戏验收要走真实鼠标操作：同一排加入并拖动扩展字形与普通符号，点预览定位同一字形，切语言后只换词，应用后新名字按预览的结构生成，读档后排列和设置仍在。再检查旧原版导入、旧模组排列、不同分辨率以及城市与生物之间切换时的字形可见性。

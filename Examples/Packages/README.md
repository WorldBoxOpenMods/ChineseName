# 命名集与词库

词库包可以独立启用，也可以一起使用。把需要的 `*.naming.json` 放进游戏「命名包」页显示的目录，重新扫描、启用并应用。它们提供独立词库和可分化的词群。城市、姓名等原版排列由本文化的命名学掌管。

## 命名集

把命名集和对应的词库文件一起放进「命名包」目录，启用这两个包并应用。「世界方案」的**世界默认文化规则**可以给整个世界使用同一套风格。「文化规则」里选中某个文化，用**基础包**选择该文化的风格并应用。语言词库可以沿用各语言当前的设置。

| 命名集 | 一起启用的词库 | 姓名、城市与国家示例 |
| --- | --- | --- |
| [国风](guofeng-set.naming.json) | [国风乡土](guofeng-lexicon.naming.json) | 沈怀瑾、槐安府、青云国 |
| [和风](wafuu-set.naming.json) | [和风人地](wafuu-lexicon.naming.json) | 佐藤明美、樱丘城、山城国 |
| [西幻](fantasy-race-set.naming.json) | [西幻诸族](fantasy-race-lexicon.naming.json) | 洛榆薇·绿叶、银柳庭、绿叶王庭 |

西幻按文化起源使用精灵、矮人或兽人的姓名、城塞和部族名。其他文化使用西式译名。国风默认用单姓，可把姓氏词组改成「国风复姓」或同时填两种词库。三套的姓氏都能沿用已有姓氏。

应用后，打开文化档案的原版「命名学」，可以直接改词组、排列和后缀。原版重置按钮恢复当前命名集的默认排列。点语言旗帜可以对照预览，语言的偏好和排除项参与实际取名。已取好的名字保留。

三套也覆盖文化、语言、家族、氏族、战争、联盟、军队、书籍、格言和装备，共 13 类。家族的默认排列沿用创始人姓氏，无姓时从当前语言抽取堂号、姓氏或氏族名。战争默认排列放入进攻国和防守国，联盟放入发起国，军队放入驻地城市。书名随书籍题材取主题词，装备名随实际材质和种类取词。各套用各自的词库组合这些部分。

例如，国风可得「河洛之风」「江渚语」「欧阳一门」「白鹭氏族」，和风可得「山城风俗」「山城语」「佐藤家」「武田一门」，西幻可得「银柳传统」「风吟语」「银枝家族」「绿叶氏族」。

三套都可以在词组里填各自的战事、盟约、军号、书名和器物词库，例如「国风战事称谓」「和风盟约称谓」「西幻军号后缀」「国风书名后缀」「和风器物名号」。文化和谱系也可以换用「国风文化词根」「国风语言词根」「国风家族堂号」「和风氏族词根」「矮人语言词根」「兽人语言词根」。

## 世界地域译名

启用[世界地域译名词库](world-styles-lexicon.naming.json)和所需的 `world-*-set.naming.json`。38 套命名集分别可选，共用这一份词库。每套覆盖姓名、城市、国家、文化、语言、家族、氏族、宗教、战争、联盟、军队、书籍、格言和装备。

| 范围 | 可以选择的地域风格 |
| --- | --- |
| 欧洲 | 不列颠、法语、德语、意大利语、古罗马拉丁、希腊、北欧、波兰、俄语、伊比利亚西语、伊比利亚葡语 |
| 西亚与中亚 | 安纳托利亚土耳其语、阿拉伯语、波斯语、蒙古草原、哈萨克草原、乌兹别克绿洲 |
| 东亚、东南亚与南亚 | 朝鲜语、越南语、泰语、马来群岛、爪哇、印度斯坦、孟加拉语、泰米尔 |
| 非洲 | 古埃及、埃塞高原、约鲁巴、斯瓦希里海岸、祖鲁 |
| 美洲 | 北美英语、墨西哥西语、纳瓦特尔、巴西葡语、安第斯克丘亚、拉普拉塔西语 |
| 大洋洲 | 毛利、萨摩亚 |

原文和中文译名保存在同一词条里。不列颠可以生成「约翰·史密斯」，朝鲜语风格按姓在前生成「金敏俊」，蒙古草原、埃塞高原等套装采用单名。地名取材于对应地区，历史地名、现代地名和创作词分组收录。游戏中的国家、制度和礼会名称以这些词条组合，适用于架空世界。

地域分组参考[联合国 M49](https://unstats.un.org/unsd/methodology/m49)。部分地名及既有汉译校对过[秘鲁](https://www.mfa.gov.cn/web/gjhdq_676201/gj_676203/nmz_680924/1206_680998/1206x0_681000/)、[埃塞俄比亚](https://www.mfa.gov.cn/web/gjhdq_676201/gj_676203/fz_677316/1206_677366/1206x0_677368/)、[乌兹别克斯坦](https://www.mfa.gov.cn/web/gjhdq_676201/gj_676203/yz_676205/1206_677052/1206x0_677054/)和[萨摩亚](https://www.mfa.gov.cn/web/gjhdq_676201/gj_676203/dyz_681240/1206_681716/1206x0_681718/)的国情资料。

## 游戏物种风格

新世界会自动使用内置物种风格。普通人族用华语姓名和地名，其他受支持的文明依文化起源取词，例如精灵用「银柳王庭」、矮人用「铁脊堡」、灵猫用「猫眼台领」。同一文化的定居者共享排列，具体用词受语言影响。野生个体、派生单位、船只和独立亚种也有对应词库。

给文化或世界选择其他基础包，或在原版命名学编辑排列，即可替换自动风格。可选的[物种风格命名集](species-set.naming.json)还能给普通人族套用「人族」主题词。物种词库已随模组加载，也能直接在其他风格的词组里用。

当前目录记录 35 组风格，包括原版四大文明、开智动物、虫群、糖裔、蒜裔、柑橘、花裔、晶铸、亡灵、菌丝、火脉和星旅等。其余几个分类区分渔船、商船、渡船。比如灵猫可用「夜瞳」「月爪」作个体名，用「猫眼台」「谧檐」作地名词根。独立亚种还可以从出生地的生境取词。

### 北欧排列与灵猫词库

启用「北欧风格」和「世界地域译名词库」，把该猫族文化的基础包设为北欧风格。在它的原版「命名学」中替换以下词组里的文字，保留右侧原有的「作为词库」字形。

| 类别 | 在原版词组填写 | 示例 |
| --- | --- | --- |
| 生物 | 给名填「灵猫个体名」，姓氏填「灵猫地名词根」 | 夜瞳·猫眼台 |
| 城市 | 地名填「灵猫地名词根」 | 猫眼台 |
| 国家 | 国号填「灵猫地名词根」，保留后面的「领」 | 猫眼台领 |

给名在前、姓氏在后，北欧的间隔号和姓氏继承字形照常生效。切换预览语言会从同一灵猫词库按各语言的偏好取词。子语言优先从该文化当前排列会用到的词库中选一项分化，并继承手调权重与排除项。其他文化可以继续用北欧原词组。

要把这套排列用到另一个世界，在命名管理中选好文化和导出时使用的语言，然后在「命名包」页点击「导出当前组合为独立基础包」。把导出的文件放入目标游戏的命名包目录，扫描、启用，再将它设为目标文化的基础包。包会携带已改的排列、词组内容、引用的词库、别名和词群。它默认提供语言词库，目标世界可以继续编辑原版命名学与各语言的用词。

## 自由组合词库

在原版「命名学」的词组中填入表里的词库名，右接「作为词库」。同一词组可以填多个名称，用空格分开。选好词库后，可以用普通词组加后缀，也可以接另一个词库。使用中的词库可以在现有「语言词库」页调整。

| 词库包 | 适用内容 | 可以直接填进词组的名称 |
| --- | --- | --- |
| [国风乡土](guofeng-lexicon.naming.json) | 古风人名、乡邑、国号、旗号与格言 | 国风单姓、国风复姓、国风双字名、国风名首字、国风名尾字、乡邑地名、国风城邑后缀、国风单字国号、国风双字国号、国风国号后缀、国风格言、国风旗号 |
| [和风人地](wafuu-lexicon.naming.json) | 姓名、地名和社寺 | 和风姓氏、和风给名、和风名首字、和风名尾字、和风地名主体、和风地名后缀、和风国名、和风社寺主体、和风社寺后缀、和风格言、和风书名主体 |
| [西幻诸族](fantasy-race-lexicon.naming.json) | 精灵、矮人和兽人的人名、城市、氏族与文献 | 精灵给名、精灵氏族名、精灵地名主体、精灵地名后缀、精灵语言词根、精灵文献、矮人给名、矮人氏族名、矮人城塞主体、矮人城塞后缀、矮人文献、兽人给名、兽人部族名、兽人地名主体、兽人领地后缀、兽人文献、西幻边地格言 |
| [宗祧编年](lineage-chronicle-lexicon.naming.json) | 堂号、族谱、纪年、封邑与史书 | 宗祧堂号、宗祧堂号后缀、宗族支房称谓、宗族字辈、编年年号、宗祧庙号、宗祧谥号、编年史书主题、编年题名后缀、谱牒后缀、封邑主体、宗祧封爵称谓 |
| [地域译名](real-world-lexicon.naming.json) | 古波斯、古埃及、拉丁、草原、不列颠及中欧 | 古波斯人名、古波斯地名、古波斯称号、古埃及人名、古埃及地名、古埃及称号、拉丁人名、拉丁族名、拉丁地名、草原人名、草原地名、草原国号后缀、不列颠地名、中欧地名 |
| [书志与器物](books-craft-lexicon.naming.json) | 各体裁题名、军号、盟约、器物名号与材料 | 史书题名尾字、博物书题名尾字、兵书题名尾字、学术书题名尾字、故事题名尾字、著述题名尾字、军号主体、军号后缀、盟约主体、盟约后缀、刃器名号、法器名号、甲衣名号、饰物名号、器物金材、器物玉材、器物木骨材 |

例如，把「和风地名主体」接「作为词库」，再接一个只填「城」的词组，可得到「樱丘城」。把「国风复姓」词组接「作为词库」和「沿用已有姓氏」，再加「国风双字名」词组及「作为词库」，则可使用带复姓的完整姓名。两个包一起启用时，同一词组也可以填写「乡邑地名 和风地名主体」。若别的包登记了同名词库，用 `chinesename/wafuu-lexicon.city-root` 这种写法指定来源。

宗祧编年包提供可用于家族名、书名等现有类别的词条。字辈、年号、庙号和谥号在这些排列里是可抽取的文字。
